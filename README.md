# Census Income Classification Project

This project trains and serves a random forest model on the provided Census Income dataset. It includes slice metrics, a FastAPI inference endpoint, API and model tests, and GitHub Actions CI with a Render deployment hook that runs only after successful checks on `main`.

## Setup and run

Use Python 3.12, matching the development environment and `.github/workflows/ci.yml`.

```bash
python -m pip install -r requirements.txt
python -m pip install -e .
python -m starter.train_model
uvicorn main:app --reload
```

The training run saves `model/model.pkl`, `model/encoder.pkl`, and `model/label_binarizer.pkl`, and writes test-set education slice metrics to `slice_output.txt`. Because these artifacts are ignored by default, explicitly stage the three final artifacts when submitting or pushing.

The API provides `GET /` and `POST /predict`. Interactive documentation is at `/docs`; the request schema preserves the dataset's hyphenated feature names and includes examples. Use `API_URL=https://<your-service-host> python live_api_request.py` to query a deployed API.

## Checks

```bash
pytest -q
flake8 .
python sanitycheck.py tests
```

GitHub Actions trains the model, then runs pytest and flake8 on pushes and pull requests to `main` or `master`. The committed submission must still include the three fitted artifacts generated by the training command. The deployment job runs after successful checks on pushes to `main` and requests that Render deploy the exact checked commit. Render auto-deploy is disabled so untested pushes do not deploy directly. Add the Render service's deploy hook as the repository secret `RENDER_DEPLOY_HOOK_URL` and connect the service to this repository/branch. The deployment job reports an error when that secret is missing. Protect `main` and require the CI checks before merging. Do not commit deployment secrets.
